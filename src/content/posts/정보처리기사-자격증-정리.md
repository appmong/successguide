정보처리기사는 IT 직무 취업과 공공기관 지원에 널리 쓰이는 국가기술자격이에요. 비전공자도 많이 도전하는데, **응시자격부터 확인해야 준비 일정을 세울 수** 있어요. 접수 방법은 [큐넷 원서접수](/cert/큐넷-원서접수-시험일정/)에 정리해 두었어요.

## 어떤 자격증인가요

- **한국산업인력공단** 이 시행하는 국가기술자격, 정보처리 분야 **기사** 등급이에요.
- 소프트웨어 설계·개발, 데이터베이스, 프로그래밍, 정보시스템 관리의 기초를 평가해요.
- 같은 분야의 하위 자격으로 **정보처리산업기사** 가 있어요.

## 응시자격

기사 등급이라 요건 중 **하나** 를 충족해야 해요. 대표적인 경로는 이래요.

| 경로 | 예시 |
| --- | --- |
| 학력 | 4년제 대학 졸업(예정). 정보처리는 관련 학과 범위가 넓어 전공이 달라도 인정되는 경우가 많아요 |
| 전문대 + 경력 | 2년제 졸업 후 일정 기간 실무 경력 |
| 하위 자격 + 경력 | 산업기사 취득 후 일정 기간 실무 경력 |
| 실무 경력 | 동일·유사 직무 일정 기간 이상 |
| 학점은행제 | 필요한 학점 충족 |

본인 경로가 애매하면 큐넷의 **응시자격 자가진단** 을 먼저 해 보세요. 경로별 자세한 판단법은 [국가기술자격 응시자격](/cert/국가기술자격-응시자격-따지는법/)에 정리해 두었어요.

## 필기: 5과목, CBT

| 과목 | 주요 내용 |
| --- | --- |
| 소프트웨어 설계 | 요구사항 분석, UML, 화면·인터페이스 설계, 디자인 패턴 |
| 소프트웨어 개발 | 자료구조, 알고리즘, 통합 구현, 테스트 |
| 데이터베이스 구축 | 데이터 모델링, 정규화, SQL, 트랜잭션 |
| 프로그래밍 언어 활용 | 언어 문법과 코드 해석, 운영체제·네트워크 기초 |
| 정보시스템 구축 관리 | 개발 방법론, 소프트웨어 보안, 시스템 구축·관리 |

- **합격 기준**: 과목당 40점 이상 + 전 과목 평균 60점 이상
- **방식**: 컴퓨터로 풀고 제출하는 **CBT** 예요. 예전처럼 공개된 회차별 기출이 새로 나오지 않아서, 기존 기출과 복원 문제로 준비하는 경우가 많아요.
- 한 과목만 과락(40점 미만)이어도 불합격이라, **약한 과목을 버리는 전략은 위험** 해요.

## 실기: 필답형

- **정보처리 실무 필답형**, 100점 만점에 60점 이상 합격
- 용어 약술, SQL 작성, **코드 실행 결과 쓰기**(C, 자바, 파이썬 등) 같은 문제가 나와요
- 필기는 보기 중에 고르지만 실기는 **직접 써야** 해서, 수험생들 사이에서는 필기보다 실기가 어렵다는 이야기가 많아요

필기에 합격하면 **정해진 기간 안에 실기** 에 응시해야 해요 → [필기 합격 유효기간](/cert/자격증-필기합격-유효기간/)

## 비전공자 준비 순서(예시)

1. **응시자격 확인** — 학점은행제가 필요하면 가장 먼저 시작(학점 인정에 시간이 걸려요)
2. **필기**: 과목별 개념을 한 번 훑고, 기출·복원 문제를 반복해 자주 나오는 부분 잡기
3. **프로그래밍 기초** 를 필기 준비 때부터 조금씩. 실기의 코드 해석에서 크게 도움이 돼요
4. **실기**: 용어는 손으로 써 보며 외우고, 코드 결과 문제는 직접 한 줄씩 따라가며 계산
5. 시험 전에는 **시간을 재고** 실전처럼 풀어 보기

전공자라면 필기는 기출 위주로 짧게, 실기에 시간을 더 배분하는 경우가 많아요.

## 취업에서의 실제 쓰임

| 쓰임 | 설명 |
| --- | --- |
| IT 직무 기본 소양 증빙 | 서류에서 전산 기초 지식을 보여 줌 |
| 공공기관·공기업 가점 | 자격 가점 대상인 경우가 많음 |
| 군 전산 특기, 일부 공무원 가산 | 직렬별로 확인 필요 |

다만 개발 직무에서는 자격증보다 **프로젝트 경험과 결과물** 을 더 중요하게 보는 곳이 많아요. 자격증은 **기초를 갖췄다는 증빙** 으로, 실제 역량은 포트폴리오로 보여 주는 조합이 좋아요 → [포트폴리오 만드는 법](/career/포트폴리오-만드는법/)

## 자주 하는 실수

- 응시자격 서류를 늦게 준비해 **합격 후 서류 미제출로 무효** 가 되는 경우
- 필기에서 한 과목을 버렸다가 **과락** 으로 불합격
- 실기를 필기처럼 눈으로만 공부해서 **막상 쓰지 못하는** 경우

과목·출제기준·일정은 바뀔 수 있으니 큐넷 공식 공고로 확인하세요. 응시자격만 갖추면 비전공자도 충분히 도전할 수 있고, 필기보다 **실기를 일찍 대비하는 것** 이 합격을 앞당기는 핵심이에요.
