시험이나 자격증을 준비할 때, 같은 시간을 써도 결과가 다른 이유는 **공부 방법** 에 있어요. 다행히 "어떻게 공부해야 오래 남는가"는 학습 심리학에서 수십 년 동안 연구된 주제라, 비교적 확실한 답이 있어요. 연구로 확인된 원리와 바로 쓰는 방법을 정리했어요.

## 1. 다시 읽기보다 떠올리기(인출)

미국 워싱턴대학교의 로디거와 카피키가 2006년에 발표한 유명한 실험이 있어요. 대학생들에게 짧은 과학 지문을 공부하게 하면서,

- 한 그룹은 **지문을 네 번 읽었고**,
- 다른 그룹은 **한 번 읽고 나머지 시간엔 기억나는 걸 적어 봤어요.**

일주일 뒤 시험을 보자 **떠올리기를 한 그룹이 훨씬 많이 기억** 했어요(약 61% 대 40%). 흥미로운 건, 공부 직후에는 여러 번 읽은 그룹이 더 자신감이 있었다는 거예요. 다시 읽으면 **익숙해서 아는 것 같은 느낌** 이 들지만, 그게 실제 기억은 아니었던 거예요.

이렇게 적용해요.

- 한 단원을 보고 나면 **책을 덮고 핵심을 말로 설명** 해 봐요.
- **빈 종이에 기억나는 걸 다 적고** 책과 비교해요.
- 문제집·기출을 **공부의 마지막이 아니라 중간** 에 풀어요.

## 2. 몰아치기보다 나눠서(분산)

같은 10시간이라면 하루에 몰아서 하기보다 **여러 날에 나눠서** 하는 게 오래 남아요. 학습 연구를 폭넓게 검토한 리뷰에서도 **떠올리기 연습과 간격 두고 나눠 하기** 두 가지가 가장 효과가 높은 방법으로 꼽혀요.

- 매일 조금씩, 여러 번 돌아오기
- 시험 전날 몰아서 하는 건 **단기 기억** 에는 도움이 되지만, 자격증처럼 필기 후 실기가 이어지는 시험에선 금방 날아가요

## 3. 복습은 살짝 잊었을 때

방금 본 걸 바로 또 보면 효과가 적고, 완전히 잊은 뒤엔 새로 배우는 셈이 돼요. **기억이 흐려지기 시작할 때** 가 복습의 적기예요.

| 복습 시점 | 방법 |
| --- | --- |
| 공부한 다음 날 | 핵심 개념 떠올리기 5~10분 |
| 3~4일 뒤 | 관련 문제 몇 개 풀기 |
| 1주일 뒤 | 단원 전체를 빈 종이에 정리 |
| 2~4주 뒤 | 기출·모의고사로 확인 |

복습 날짜를 **캘린더에 미리 적어** 두면 잊지 않아요. 복습은 항상 **읽기가 아니라 떠올리기** 로 해요.

## 4. 한 가지만 파기보다 섞어서

한 유형 문제를 20개 연달아 푸는 것보다, **여러 유형을 섞어서** 푸는 게 실전에 강해요. 시험에서는 문제가 섞여 나오기 때문에, "이게 어떤 유형인지 알아보는 능력"까지 연습이 돼요. 연습할 땐 더 어렵게 느껴지지만 그게 정상이에요.

## 5. 이해가 먼저, 암기는 그다음

무작정 외우기보다 **왜 그런지** 를 먼저 잡으면 훨씬 잘 붙어요. 흐름, 원인과 결과, 구조를 먼저 이해하고 세부 암기는 그 위에 얹어요. 한국사처럼 흐름이 있는 과목은 특히 그래요 → [한능검 정리](/cert/한국사능력검정-급수-정리/)

## 아는 것 같은 착각 피하기

| 착각 | 실제 |
| --- | --- |
| 형광펜을 많이 칠했으니 공부했다 | 표시는 공부가 아니에요. 떠올려 봐야 남아요 |
| 세 번 읽었으니 안다 | 횟수보다 "책 없이 설명할 수 있나"가 기준이에요 |
| 문제를 보면 답이 기억난다 | 보기가 있으면 쉬워요. 보기 없이 떠올려 보세요 |
| 오늘 공부가 잘 됐다(술술 읽혔다) | 술술 읽힐수록 기억엔 덜 남는 경우가 많아요 |

## 오늘부터 바로 쓰는 루틴

1. 25~50분 공부(→ [시간관리](/career/시간관리-뽀모도로-생산성/))
2. 책 덮고 **3분 동안 핵심 말하기 또는 적기**
3. 틀린 부분만 다시 확인
4. 다음 날 같은 내용을 **5분 떠올리기**
5. 주말에 한 주 치를 **섞어서 문제 풀기**

오답은 "왜 틀렸는지"까지 한 줄로 적어 두면 같은 실수를 줄일 수 있어요.

정리하면 **떠올리기, 나눠서, 간격 두고 복습, 섞어서** 네 가지예요. 공부가 좀 더 힘들게 느껴진다면 제대로 하고 있다는 신호일 수 있어요. 오늘 공부 끝에 **책 덮고 요약하기** 한 가지만 더해 보세요.
