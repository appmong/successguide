서류를 통과하면 많은 기업과 공공기관이 **필기전형** 을 봐요. 대기업은 인적성검사, 공공기관은 NCS 직업기초능력평가가 대표적이에요. 처음엔 생소하지만, **유형을 알고 시간 배분을 연습하면** 점수가 확실히 올라가는 시험이에요.

## 인적성과 NCS

| 구분 | 인적성검사 | NCS 직업기초능력평가 |
| --- | --- | --- |
| 주로 쓰는 곳 | 대기업, 중견기업 | 공공기관, 공기업 |
| 평가 | 인지능력(언어·수리·추리 등) + 인성 | 10개 직업기초능력 중 기관이 고른 영역 + 인성 |
| 특징 | 기업마다 유형과 이름이 다름 | 업무 상황을 가정한 문제가 많음 |
| 시험 방식 | 온라인 또는 오프라인 | 대부분 오프라인 |

먼저 **지원할 곳이 어떤 유형을 보는지** 채용 공고와 후기로 확인하는 게 출발점이에요.

## NCS 10개 영역

한국산업인력공단이 정한 직업기초능력은 10개 영역이에요. 기관마다 이 중 몇 개를 골라 출제해요.

| 영역 | 하위 능력 |
| --- | --- |
| 의사소통능력 | 문서 이해·작성, 경청, 의사 표현, 기초 외국어 |
| 수리능력 | 기초 연산, 기초 통계, 도표 분석·작성 |
| 문제해결능력 | 사고력, 문제 처리 |
| 자원관리능력 | 시간·예산·물적·인적 자원 관리 |
| 정보능력 | 컴퓨터 활용, 정보 처리 |
| 조직이해능력 | 국제 감각, 조직 체제·경영·업무 이해 |
| 자기개발능력 | 자아 인식, 자기 관리, 경력 개발 |
| 대인관계능력 | 팀워크, 리더십, 갈등 관리, 협상, 고객 서비스 |
| 기술능력 | 기술 이해·선택·적용 |
| 직업윤리 | 근로 윤리, 공동체 윤리 |

많은 기관이 **의사소통, 수리, 문제해결** 을 기본으로 넣고, 직무에 따라 자원관리·정보·조직이해 등을 더해요.

## 문제 스타일

수험생들 사이에서는 NCS 문제 스타일을 흔히 이렇게 나눠 불러요.

| 스타일 | 특징 | 준비 |
| --- | --- | --- |
| 모듈형 | NCS 학습 모듈의 이론·개념을 묻는 문제 | 영역별 핵심 이론 정리 |
| PSAT형 | 긴 자료·표를 읽고 추론·계산하는 문제 | 자료 해석 속도 연습 |
| 혼합형(피듈형) | 두 스타일이 섞임 | 이론은 빠르게, 자료 해석에 시간 배분 |

지원 기관의 최근 후기를 보면 어느 스타일에 가까운지 감이 와요. 한국산업인력공단 NCS 누리집에는 **채용 모델 필기 문항** 예시도 공개돼 있어요.

## 핵심은 시간 배분

인적성과 NCS는 대부분 **시간 안에 다 풀기 어렵게** 설계돼 있어요. 다 풀려고 하다가 앞에서 시간을 다 써 버리는 게 가장 흔한 실패예요.

- **한 문제 1분 넘으면 표시하고 넘기기**, 끝에 돌아오기
- **자신 있는 영역·유형부터** 풀기
- 자료 해석은 **질문을 먼저 읽고 필요한 숫자만** 찾기
- 계산은 정확한 값보다 **대략 비교** 로 보기를 지울 수 있는지 먼저 보기
- 오답 감점이 있는지 공고에서 확인하고, 찍을지 비울지 전략 정하기

## 준비 일정(시험 4주 전 기준)

| 시기 | 할 일 |
| --- | --- |
| 4주 전 | 지원처 유형 파악, 영역별 유형 한 번씩 풀어 보기 |
| 3주 전 | 약한 영역 집중, 오답 노트 |
| 2주 전 | **시간 재고** 모의고사, 주 2~3회 |
| 1주 전 | 실전 시간표대로 모의고사, 컨디션 조절 |
| 전날 | 새 문제보다 오답 복습, 일찍 자기 |

## 인성검사 요령

- 정답이 있는 시험이 아니에요. **솔직하고 일관되게** 답해요.
- 비슷한 질문이 표현만 바꿔 여러 번 나와요. 지나치게 좋게만 답하면 **일관성 점검** 에 걸릴 수 있어요.
- 문항이 많고 시간이 짧아서 **직관적으로 빠르게** 답해요.
- 지원 기관의 인재상을 한 번 읽고 가되, 억지로 맞추진 않아요.

## 자주 하는 실수

- 유형 파악 없이 아무 문제집이나 풀기
- 시간 재는 연습 없이 개념만 보기
- 모르는 문제에 붙잡혀 뒤쪽 쉬운 문제를 못 풀기
- 인성검사에서 과하게 포장하기
