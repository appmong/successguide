이직은 "지금 회사가 싫어서"만으로 움직이면 후회하기 쉬워요. 방향을 정하고 **차분히 준비** 하면 더 좋은 자리로 옮길 확률이 높아지고, 마무리까지 깔끔하게 할 수 있어요.

## 재직 중 준비가 유리한 이유

- **소득 공백이 없어서** 급하게 아무 곳이나 가지 않게 돼요.
- 당장 옮기지 않아도 되니 **처우 협상에서 여유** 가 생겨요.
- 시장 반응을 보며 **천천히 고를 수** 있어요.

재직 중 준비는 **조용히** 해요. 업무는 평소처럼 성실하게, 이직 이야기는 가족이나 믿을 만한 사람에게만.

## 1단계: 이직 사유를 한 문장으로

"왜 옮기는가?"를 분명히 해야 옮길 곳의 기준이 서고 면접 답변도 흔들리지 않아요.

| 사유 | 옮길 곳에서 확인할 것 |
| --- | --- |
| 연봉 | 기본급 구성, 성과급 지급 이력 |
| 성장 | 맡게 될 역할의 범위, 교육·승진 제도 |
| 직무 | 실제로 하게 될 업무(면접에서 질문) |
| 환경 | 근무 형태, 팀 분위기, 출퇴근 |

면접에서 이전 직장을 비난하는 말은 피하고, **"무엇을 더 하고 싶어서"** 로 표현해요. 직무 자체를 바꾸고 싶다면 [직무 전환 준비](/career/직무전환-커리어피벗-준비/)를 먼저 보세요.

## 2단계: 성과 정리

- 그동안의 **성과를 숫자로** 정리해요(매출, 비용 절감, 처리 시간, 고객 수).
- 이력서와 **경력기술서** 를 최신으로 → [경력기술서 작성법](/job/경력기술서-작성법/)
- 프로필 사이트를 쓴다면 **현 직장이 볼 수 있는지** 공개 범위를 확인해요.
- 추천해 줄 수 있는 사람(평판 조회 대상)을 미리 생각해 둬요.

## 3단계: 시장 파악

- 목표 직무의 **공고 10개** 를 모아 요구 역량을 확인해요.
- 내 경력과 **차이** 가 있으면 보완 계획을 세워요(자격증, 프로젝트).
- 같은 직무·연차의 **연봉 수준** 을 알아 두면 협상 기준이 생겨요 → [연봉·처우 협상](/job/연봉협상-처우협의-하는법/)

## 4단계: 지원과 면접

- **맞는 공고에 집중** 해요. 재직 중엔 시간이 부족해서 대량 지원이 오히려 비효율이에요.
- 면접 일정은 **연차, 반차, 점심시간 전후** 로 조율해요. 요즘은 첫 면접을 화상으로 보는 곳도 많아요.
- 합격하면 처우 협의 → **입사 조건을 서면(처우 안내, 근로계약서)으로** 확인해요.

## 5단계: 퇴사 통보

**새 회사 입사가 서면으로 확정된 뒤** 에 알려요.

알아 둘 법적 기준도 있어요.

- 근로기준법의 '30일 전 예고'는 **회사가 해고할 때** 의 규정이에요. 근로자가 그만둘 때 30일 전 통보 의무가 법으로 정해진 건 아니에요.
- 다만 회사가 사직서를 **받아 주지 않으면**, 민법 제660조에 따라 통보 후 **1개월**(월급제라면 통보한 달의 다음 달이 지난 시점)이 지나야 퇴직 효력이 생겨요.
- 그래서 실무에서는 **한 달 전쯤** 알리고, 인수인계 기간을 협의하는 게 서로 안전해요.
- 취업규칙이나 근로계약서에 사직 통보 기간이 적혀 있다면 그것도 확인해요.

## 6단계: 마무리와 챙길 것

| 항목 | 내용 |
| --- | --- |
| 퇴직금 | 1년 이상 근무 시, 퇴직일로부터 **14일 안에** 지급이 원칙 |
| 연차수당 | 남은 연차는 수당으로 정산(퇴직금과 함께) |
| 경력증명서 | 회사는 요청 시 발급해야 해요. 퇴사 전에 미리 받아 두면 편해요 |
| 원천징수영수증 | 새 회사 연말정산에 필요 |
| 4대보험 상실 | 회사가 처리, 새 회사 취득일과 겹치지 않는지 확인 |

인수인계는 **문서로** 남겨요. 업계는 생각보다 좁아서, 마지막 인상이 평판으로 오래 남아요.

## 조심할 것

- **홧김 퇴사 후 준비**: 공백이 길어지면 급해져서 불리해요.
- **구두 합격만 믿고 통보**: 처우가 바뀌거나 채용이 취소되는 경우도 있어요.
- **연봉만 보고 이동**: 직무와 환경이 맞지 않으면 다시 이직을 고민하게 돼요.
- **현 직장 자료 반출**: 회사 문서나 고객 정보를 가져가면 법적 문제가 될 수 있어요.

## 체크리스트

- [ ] 이직 사유 한 문장 정리
- [ ] 성과를 숫자로, 경력기술서 최신화
- [ ] 목표 직무 요구 역량 확인
- [ ] 입사 확정을 서면으로 받은 뒤 퇴사 통보
- [ ] 인수인계 문서 작성
- [ ] 퇴직금·연차수당·경력증명서·원천징수영수증 확인

이직은 **재직 중에, 사유를 분명히, 확정 뒤에 통보, 깔끔하게 마무리** 가 핵심이에요. 법적 기준은 개별 상황에 따라 다를 수 있으니, 분쟁이 생기면 고용노동부 상담센터(1350)에 문의하세요.
