디자인, 개발, 기획, 마케팅처럼 결과물이 있는 직무에서는 포트폴리오가 이력서만큼 중요해요. 그런데 **작업을 몽땅 모아 두는 것** 은 오히려 인상을 흐려요. 채용 담당자가 한 포트폴리오에 쓰는 시간은 길지 않아서, 첫 몇 장에서 "이 사람은 이 일을 할 수 있다"가 보여야 해요.

## 포트폴리오가 보여줘야 하는 것

포트폴리오는 "이런 걸 만들었다"를 넘어서 **"이 직무를 이렇게 해낼 수 있다"** 를 보여 주는 자료예요. 평가하는 사람은 결과물 개수보다 이런 걸 봐요.

- 어떤 **문제** 를 풀려고 했는지
- **왜** 그렇게 접근했는지(생각하는 방식)
- **내가** 무엇을 했는지
- 결과가 **어땠는지**

## 대표작 3~5개 고르기

| 기준 | 설명 |
| --- | --- |
| 직무 관련성 | 지원 직무와 가장 가까운 작업 |
| 완성도 | 끝까지 완성한 것, 어중간한 작업은 빼기 |
| 다양성 | 비슷한 작업 여러 개보다 서로 다른 역량이 보이는 조합 |
| 최신성 | 오래된 작업만 있으면 성장이 멈춘 것처럼 보여요 |

가장 강한 작업을 **맨 앞에** 둬요. 끝까지 안 보는 경우가 많아요.

## 프로젝트 정리 틀: 문제 → 과정 → 결과

| 항목 | 내용 |
| --- | --- |
| 개요 | 무엇을, 왜, 기간과 규모(팀 인원) |
| 나의 역할 | 팀이면 내가 맡은 부분, 기여 비율 |
| 문제·목표 | 해결하려던 문제, 목표 지표 |
| 과정 | 어떤 선택을 했고 왜 그랬는지, 버린 대안 |
| 결과 | 성과(가능하면 숫자), 배운 점, 다시 한다면 바꿀 점 |

### 예시(마케팅 직무 개인 프로젝트)

- **개요**: 동네 카페 인스타그램 계정 운영 제안(4주, 개인)
- **문제**: 게시물은 꾸준한데 반응이 거의 없음
- **과정**: 지난 3개월 게시물 60개를 분석해 반응이 좋았던 시간대와 사진 유형을 찾음 → 게시 시간을 저녁으로 옮기고 메뉴 클로즈업 사진 비중을 늘리는 안을 제안
- **결과**: 4주 동안 게시물당 평균 반응 2.3배, 사장님이 이후에도 같은 방식으로 운영
- **배운 점**: 감이 아니라 과거 데이터로 가설을 세우는 게 설득에 훨씬 효과적이었음

"다시 한다면 바꿀 점"을 한 줄 넣으면 **스스로 돌아볼 줄 아는 사람** 이라는 인상을 줘요.

## 팀 프로젝트에서 내 역할 드러내기

팀 작업에서 **"우리"만 있고 "나"가 없으면** 평가하기 어려워요.

- 내가 맡은 파트를 **색이나 표시** 로 구분해요.
- "팀이 ~했다"가 아니라 "나는 ~를 맡아 ~했다"로 써요.
- 협업하며 조율한 과정도 좋은 소재예요.

## 직무별 포인트

| 직무 | 보여줄 것 |
| --- | --- |
| 디자인 | 결과 이미지 + 의도, 시안 비교, 사용자 조사 근거 |
| 개발 | 역할, 기술 선택 이유, 해결한 어려운 문제, 저장소·데모 링크 |
| 기획 | 문제 정의, 사용자 흐름, 화면 설계, 지표 |
| 마케팅 | 목표, 전략, 실행, 성과 지표, 예산 대비 효과 |
| 데이터 | 질문, 데이터 출처, 분석 방법, 결론과 한계 |

## 형식과 분량

- **PDF 한 파일** 이 가장 무난해요. 용량이 너무 크면 이미지 해상도를 줄여요.
- 분량은 **15~30쪽 안팎** 이 흔해요. 공고에 제한이 있으면 반드시 지켜요.
- 개발·디자인은 **온라인 링크** 를 함께 두면 좋아요. 링크가 **실제로 열리는지** 제출 전 확인해요.
- 파일명은 **이름_직무_포트폴리오**.

## 경력이 없을 때

- **실제 서비스 분석 + 개선 제안**: 자주 쓰는 앱이나 가게의 문제를 찾아 개선안을 만들어요.
- **공모전·해커톤**: 주어진 과제와 마감이 있어 완성도 있는 결과가 나와요.
- **수업 과제 다시 다듬기**: 피드백을 반영해 한 단계 발전시킨 과정을 보여 줘요.
- **작게라도 실제로 운영해 보기**: 블로그, SNS, 작은 판매처럼 숫자가 나오는 경험.

직무를 바꾸려는 경우라면 [직무 전환 준비](/career/직무전환-커리어피벗-준비/)와 함께 보세요.

## 흔한 실수

- 양으로 승부하기
- 결과만 있고 과정과 역할이 없기
- 내용보다 꾸밈이 앞서기
- 오타, 깨진 링크
- 한 번 만들고 업데이트하지 않기

포트폴리오는 **잘 고른 대표작을, 문제·과정·결과로, 내 역할을 분명히** 보여주는 자료예요. 오늘은 대표작 하나를 이 틀로 다시 정리해 보세요.
