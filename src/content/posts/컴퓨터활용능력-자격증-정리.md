컴퓨터활용능력(컴활)은 사무직 취업 준비생이 가장 많이 찾는 자격증 중 하나예요. 그런데 1급과 2급 중 무엇을 따야 할지, 필기와 실기는 어떻게 다른지 헷갈리기 쉽죠. 급수 차이와 합격 기준, 공부 순서를 정리했어요.

## 어떤 자격증인가요

- **대한상공회의소** 가 시행하는 국가기술자격이에요.
- 엑셀(스프레드시트)과 액세스(데이터베이스)를 **실무 수준으로 다루는 능력** 을 평가해요.
- 사무·행정·회계 직무, 공공기관 가산점 등에 많이 쓰여요.

## 1급과 2급

| 구분 | 2급 | 1급 |
| --- | --- | --- |
| 필기 과목 | 컴퓨터 일반, 스프레드시트 일반 | 컴퓨터 일반, 스프레드시트 일반, 데이터베이스 일반 |
| 실기 과목 | 스프레드시트 실무 | 스프레드시트 실무 + 데이터베이스 실무 |
| 준비 기간(개인차 큼) | 몇 주 | 몇 달 |
| 쓰임 | 일반 사무직에 무난 | 데이터·회계 직무, 공공기관 가산점에 유리 |

핵심 차이는 **액세스(데이터베이스)** 예요. 1급은 엑셀도 더 어려운 함수와 기능이 나오고, 액세스까지 익혀야 해서 준비 기간이 크게 늘어나요.

## 합격 기준

| 시험 | 기준 |
| --- | --- |
| 필기 | 과목당 40점 이상 + 평균 60점 이상 |
| 실기(2급) | 70점 이상 |
| 실기(1급) | 스프레드시트, 데이터베이스 **두 과목 모두** 70점 이상 |

1급 실기는 한 과목만 70점을 넘어도 불합격이에요. 엑셀은 자신 있는데 액세스가 약해서 떨어지는 경우가 많아요.

## 시험 방식과 유효기간

- **상시 시험(CBT)** 이라 연중 원하는 날짜와 시험장을 골라 응시할 수 있어요. 인기 시험장은 빨리 마감돼요.
- 필기에 합격하면 **2년 안에** 실기에 합격해야 해요. 넘기면 필기부터 다시예요 → [필기 합격 유효기간](/cert/자격증-필기합격-유효기간/)
- 응시료와 세부 일정은 대한상공회의소 자격평가사업단 누리집에서 확인하세요.

## 어떤 급수를 딸까

| 목표 | 추천 |
| --- | --- |
| 일반 사무, 행정 지원 | 2급으로 충분한 경우가 많음 |
| 회계, 데이터 처리 직무 | 1급이 유리 |
| 공공기관 가산점 | 기관별 인정 급수 확인(1급·2급 가점이 다른 곳 많음) |
| 시간이 촉박함 | 2급 먼저, 여유가 생기면 1급 |

목표 기업의 **우대사항** 에 어떤 급수가 적혀 있는지 먼저 확인하세요 → [채용공고 읽는 법](/job/채용공고-읽는법-직무정하기/)

## 공부 순서

1. **필기**: 컴퓨터 일반은 암기 위주, 스프레드시트는 실기와 겹쳐서 함께 익히면 효율적이에요. 기출 문제를 반복해요.
2. **필기 합격 직후 실기 시작**: 필기 내용이 남아 있을 때가 가장 좋아요.
3. **엑셀 실기**: 자주 나오는 함수(조건, 조회, 날짜, 텍스트)와 기능(조건부 서식, 피벗 테이블, 매크로)을 유형별로 정리해요.
4. **1급이라면 액세스**: 테이블, 쿼리, 폼, 보고서 작업을 반복해요. 처음 써 보는 프로그램이라 시간을 넉넉히 잡아요.
5. **실전 연습**: 시험 시간에 맞춰 기출·모의 문제를 풀어요. 시간 안에 **부분 점수라도 챙기는** 연습이 중요해요.

## 실기는 손이 기억해야 해요

- 실기는 **이해했다고 끝이 아니라 손이 기억할 때까지** 반복해야 해요. 눈으로 강의만 보면 시험장에서 손이 안 움직여요.
- 어려운 함수 한 문제에 매달리지 말고, **배점이 큰 작업부터** 끝내요.
- 실수로 원본 데이터를 지우거나 시트 이름을 바꾸면 감점이 커요. 작업 전에 문제 조건을 꼼꼼히 읽어요.

## 실무에서의 쓰임

컴활 1급 수준의 엑셀을 다룰 수 있으면 실제 업무에서 **데이터 정리와 보고서 작성 시간** 이 크게 줄어요. 자격증 자체보다 **"이 기능을 써서 이런 업무를 빠르게 했다"** 는 경험으로 연결하면 자소서와 면접에서 훨씬 힘이 있어요.

컴활은 **목표에 맞는 급수를 고르고, 실기 반복에 시간을 넉넉히** 두는 게 핵심이에요. 과목과 기준은 바뀔 수 있으니 시행처 공식 안내로 꼭 확인하세요.
