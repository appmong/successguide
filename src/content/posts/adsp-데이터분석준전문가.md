"데이터 분석 직무에 관심 있는데 뭐부터 따야 하나요?"라는 질문에 가장 많이 나오는 답이 **SQLD와 ADsP**예요. 둘 다 한국데이터산업진흥원이 시행하는 국가공인 민간자격이고 응시 자격 제한이 없어요. SQLD가 SQL 문법 중심이라면, **ADsP(데이터분석 준전문가)** 는 데이터 분석의 큰 흐름과 통계·머신러닝 기초 개념을 묻는 시험이에요. SQLD는 [SQLD 자격증 정리](/cert/sqld-자격증-정리/)에 따로 정리했어요.

## 시험 구성과 합격 기준

| 과목 | 문항 | 주요 내용 |
| --- | --- | --- |
| 1과목 데이터 이해 | 10 | 데이터와 정보, 데이터베이스, 빅데이터 개념, 데이터 사이언스 |
| 2과목 데이터 분석 기획 | 10 | 분석 과제 도출, 분석 방법론, 분석 마스터플랜 |
| 3과목 데이터 분석 | 30 | R 기초, 통계 분석(회귀·검정), 정형 데이터 마이닝(분류·군집·연관) |

- **객관식 50문항, 90분**, 필기 한 번으로 끝
- **총점 60점 이상**, 과목별 **40% 미만이면 과락**
- 과락 기준으로 보면 1·2과목은 각 4문항, 3과목은 12문항 이상 맞혀야 해요

3과목이 전체의 60%라서 **통계와 데이터 마이닝 개념**이 합격을 좌우해요. 반대로 1·2과목은 암기 위주라 짧게 끝낼 수 있지만, 과락이 걸리지 않게 놓치지는 말아야 해요.

## 2026년 일정과 다음 준비

2026년에는 연 4회(제48~51회) 시험이 열렸어요. 마지막인 **제51회는 접수가 끝났고, 10월 31일(토) 시험, 11월 20일 결과 발표**예요. 지금 처음 준비한다면 **2027년 상반기 첫 회차**를 목표로 잡으면 돼요. 다음 해 일정은 보통 연말~연초에 데이터자격검정 누리집에 공지돼요. 응시료와 접수 일정은 접수 전에 공식 공고로 확인하세요.

## SQLD와 무엇이 다를까

| 구분 | SQLD | ADsP |
| --- | --- | --- |
| 핵심 | SQL 문법과 데이터 모델링 | 분석 기획, 통계, 데이터 마이닝 개념 |
| 공부 방식 | 쿼리를 직접 실행하며 익힘 | 개념 이해 + 용어 구분 |
| 어울리는 직무 | 데이터 추출·운영, 개발, 기획 | 데이터 분석, 마케팅 분석, 기획 |
| 난이도 체감 | 문법이 익숙하면 수월 | 통계가 처음이면 3과목이 벽 |

**두 자격 모두 실무 능력을 직접 증명하지는 않아요.** 기초를 공부했다는 신호 정도라서, 공부한 내용을 짧은 분석 결과물로 만들어 두면 면접에서 훨씬 설득력이 있어요. → [포트폴리오 만드는 법](/career/포트폴리오-만드는법/)

## 공부 순서 (비전공자 기준 4~6주)

1. **1주차: 1·2과목** — 용어 위주로 빠르게 정리(데이터·정보·지식·지혜 구분, 분석 방법론 단계)
2. **2주차: 통계 기초** — 평균·분산·표준편차, 표본과 모집단, 가설검정(귀무가설, p-값)
3. **3주차: 회귀분석** — 단순·다중 회귀, 결정계수, 다중공선성, 변수 선택법
4. **4주차: 데이터 마이닝** — 의사결정나무, 로지스틱 회귀, 군집분석(k-평균), 연관규칙(지지도·신뢰도·향상도), 분류 모형 평가(정확도·정밀도·재현율)
5. **5~6주차: 기출 변형 문제 반복** — 틀린 개념을 한 줄 요약 노트로 정리

통계를 처음 접한다면 공식을 외우기보다 **"이 값이 크면 무슨 뜻인지"** 를 말로 설명할 수 있게 공부하는 게 좋아요. 기억을 오래 남기는 방법은 [인출·분산 학습](/career/공부-잘하는법-인출-분산학습/)을 참고하세요.

## 자주 막히는 개념

- **정밀도와 재현율**: "양성이라고 예측한 것 중 진짜 양성 비율"이 정밀도, "진짜 양성 중 맞힌 비율"이 재현율이에요. 혼동행렬을 직접 그려 보면 덜 헷갈려요.
- **p-값**: 귀무가설이 맞다고 할 때 지금 같은 결과가 나올 확률이에요. 작을수록 귀무가설을 기각할 근거가 강해요.
- **연관규칙 향상도**: 1보다 크면 두 상품이 함께 팔리는 관계가 우연보다 강하다는 뜻이에요.
- **군집분석과 분류**: 정답(라벨)이 없으면 군집, 있으면 분류예요.
