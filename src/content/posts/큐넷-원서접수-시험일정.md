기사, 산업기사, 기능사 같은 국가기술자격을 처음 준비하면 "어디서 어떻게 접수하지?"에서 막혀요. 결론부터 말하면 **큐넷(Q-net) 한 곳** 에서 다 해요. 다만 접수 기간이 짧고 인기 시험장은 금방 차서, **미리 준비해 두지 않으면** 원하는 회차를 놓치기 쉬워요.

## 큐넷에서 하는 일

| 단계 | 큐넷 메뉴 |
| --- | --- |
| 시험일정 확인 | 시험일정 |
| 응시자격 확인 | 응시자격 자가진단 |
| 원서접수·취소 | 원서접수, 마이페이지 |
| 수험표 출력 | 마이페이지 |
| 합격자 발표 | 합격자 발표 |
| 응시자격 서류 제출 | 서류 제출(해당 종목) |
| 자격증 발급 | 자격증 발급 |

## 1. 시험일정부터 확인

종목마다 **시행 회차와 접수 기간** 이 정해져 있어요.

- 정기 기사·산업기사·기능사는 **1년에 여러 회차** 로 나뉘어요.
- 흐름은 **필기 접수 → 필기 시험 → 합격 발표 → 실기 접수 → 실기 시험 → 최종 발표** 예요.
- 접수 기간은 보통 **며칠로 짧아요.** 시작일과 마감일을 캘린더에 적고 알림을 걸어 두세요.

## 2. 접수 전에 미리 해 둘 것

**회원가입과 사진 등록** 은 접수 기간 전에 끝내 두세요. 접수 첫날 사진 때문에 막히면 시험장이 다 찰 수 있어요.

| 항목 | 기준 |
| --- | --- |
| 사진 | 증명사진(2.5×3.5cm) 또는 반명함판(3×4cm), 정면, 이마·눈썹·눈·코·입이 잘 보이게 |
| 파일 | JPG·JPEG, 200KB 이하 |
| 등록 불가 예시 | 측면 사진, 배경이 복잡함, 얼굴 여백이 부족함 |

응시자격이 필요한 종목(기사·산업기사 등)이라면 **자가진단** 도 미리 해 봐요 → [국가기술자격 응시자격](/cert/국가기술자격-응시자격-따지는법/)

## 3. 원서접수 순서

1. 큐넷 로그인
2. 원서접수 → **종목·회차 선택**
3. **시험장 선택**(지역과 날짜)
4. 응시료 결제
5. 접수 완료 → **수험표 출력**(시험 전날 다시 확인)

### 접수 첫날이 몰리는 이유

인기 종목은 **접수 시작 시각에 접속자가 몰리고, 가까운 시험장부터 빠르게 마감** 돼요. 수험생들 사이에서는 "접수 첫날 오전이 승부"라는 말이 나올 정도예요.

- 접수 시작 **10~20분 전에 로그인** 해 두기
- **원하는 시험장 2~3곳** 을 미리 정해 두기
- PC와 휴대폰 중 **안정적인 쪽** 으로 접수
- 가까운 시험장이 다 찼다면 추가 시험장이 열리는지 공지를 확인하기

## 4. 취소와 환불

| 취소 시점 | 환불 |
| --- | --- |
| 접수 기간 안 | **100%** |
| 접수 기간이 끝난 뒤 ~ 시험 시행일 5일 전 | **50%** |
| 그 이후 | 환불 없음 |

취소는 마이페이지의 원서접수 내역에서 해요. 접수 기간 마지막 날 늦은 밤에는 은행 사정으로 환불 처리가 늦어질 수 있어요.

## 5. 필기 합격 후

- 필기에 합격하면 **합격 발표일로부터 2년** 동안 필기가 면제돼요. 그 안에 실기에 합격해야 해요 → [필기 합격 유효기간](/cert/자격증-필기합격-유효기간/)
- 응시자격이 필요한 종목은 **서류 제출 기한** 안에 꼭 내야 해요. 놓치면 합격이 무효가 될 수 있어요.
- 실기 접수 일정도 바로 캘린더에 옮겨 적어요.

## 6. 최종 합격 후 자격증 발급

| 형태 | 특징 |
| --- | --- |
| 상장형 | 인터넷으로 신청, 수수료 없이 바로 출력 가능 |
| 수첩형 | 신청 후 승인까지 1~2주 정도, 우편 또는 방문 수령 |
| 모바일 | 상장형이나 수첩형을 발급받은 사람이 추가로 발급 가능 |

채용 서류에 낼 때는 공고에서 어떤 형태를 인정하는지 확인하세요. 대부분 **자격증 사본이나 큐넷의 자격 취득 확인서** 로 충분해요.

## 자주 하는 실수

- 사진 규격 오류로 접수 첫날 막힘
- 접수 기간을 놓쳐 다음 회차까지 기다림
- 필기 합격 후 **응시자격 서류 미제출**
- 수험표 확인 없이 **다른 시험장** 으로 감
- **신분증** 을 두고 옴(인정되는 신분증 종류도 공고에서 확인)

## 접수 체크리스트

- [ ] 종목 시험일정과 접수 기간을 캘린더에
- [ ] 회원가입과 사진 등록을 미리
- [ ] 응시자격 자가진단
- [ ] 희망 시험장 2~3곳 정해 두기
- [ ] 접수 후 수험표 출력, 신분증 준비

시험 공부만큼 중요한 게 **제때 접수하기** 예요. 준비하는 종목의 일정을 오늘 큐넷에서 확인해 두세요. 응시료와 세부 일정은 회차마다 달라질 수 있으니 큐넷 공식 공고를 기준으로 하세요.
